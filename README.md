# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面。页面是手写脚本，没有用组件框架，也没有图表。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3191 |
| 接口 | http://localhost:8191 |
| PostgreSQL | localhost:54391 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| gasman | gas123456 | 可上报、可改每测点每小时上报次数门槛 |
| viewer | view123456 | 只能看：可看记录与超次尝试册，不能上报、不能改门槛 |

## 超次规则

- 同一测点在同一时钟小时内最多上报检查员设定的次数（默认 3 次），超出后服务端拒绝（HTTP 429）。
- 超次请求会记入**超次尝试册**：测点、操作者、时刻、当时门槛。
- 门槛可由检查员随时修改，改完只影响之后的请求，不追溯历史记录。
- 换一个测点名不受同一测点的次数限制，仍可正常上报。

## 启动

```bash
cd projects/12-mine-methane-shift
docker compose up --build
```

## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常。
2. 再开一个浏览器窗口同时看列表，上报一个大于等于 1 的测点，两个窗口都会出现新记录。
3. viewer 登录后没有上报表单，门槛输入框只读且没有修改按钮，但能看到超次尝试册。
4. gasman 把门槛设成 1：对“东翼-12”连续报第二笔应被拒（429），并在超次尝试册出现一条记录（测点、操作者、时刻、当时门槛为 1）。
5. 换一个测点名上报仍可成功。
6. 门槛改回更大的值后，下一小时或对新测点立即恢复可报。
