# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面。页面是手写脚本，没有用组件框架，也没有图表。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3191 |
| 接口 | http://localhost:8191 |
| PostgreSQL | localhost:54391 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| gasman | gas123456 | 可上报 |
| viewer | view123456 | 只能看 |

## 启动

```bash
cd projects/12-mine-methane-shift
docker compose up --build
```

## 次数门槛与超次尝试册

- 同一测点在同一自然小时内，最多上报检查员设定的次数（默认 3）。超出后该笔被拒绝（HTTP 429），并写入**超次尝试册**。
- 检查员（gasman）可在页面上修改门槛；改动即时生效，只影响之后的请求，不回补或追溯已拒绝/已通过的记录。
- 尝试册记录：测点、操作者、时刻、当时门槛。门槛后来再改，旧记录保留当时的门槛值。
- 旁观账号（viewer）能看尝试册和读数，但不能改门槛，也不能上报。
- 开机自带的演示数据（东翼-12、回风巷）不计入每小时次数。

相关接口：`GET /api/limit`、`PUT /api/limit`（仅检查员）、`GET /api/over-limit-attempts`（登录即可）。

## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常。
2. 再开一个浏览器窗口同时看列表，上报一个大于等于 1 的测点，两个窗口都会出现新记录。
3. viewer 登录后没有上报表单。
4. gasman 把每小时门槛改成 **1**，对测点「东翼」连续报第二笔：第二笔被拒（提示已达上限），并自动出现在下方「超次尝试册」，册中含测点、操作者、时刻、当时门槛（1）。
5. 换一个测点名（如「西翼」）仍可正常上报。
6. viewer 登录能看到超次尝试册，但页面没有改门槛入口；直接调 `PUT /api/limit` 或上报接口都返回 403。
